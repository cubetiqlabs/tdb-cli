## 2024-08-23 - Exposed API Keys in CLI configuration commands
**Vulnerability:** The CLI prints the full, plaintext API Key for stored tenants when running `tdb config show` and `tdb config list --raw`. It does mask the `admin_secret` but leaves tenant `APIKeyEntry.Key` fully exposed.
**Learning:** Config commands that output the persisted struct directly via JSON or YAML marshaling will leak any credentials if they are part of the struct definition and not explicitly masked beforehand (or custom marshaled). A shallow copy of the struct is not enough when it contains maps of nested objects, as maps are passed by reference and mutations to them affect the original struct.
**Prevention:** Implement deep cloning (or explicitly iterating/rebuilding structures) to properly mask all sensitive keys in nested maps before serializing the configuration for display purposes. Ensure to copy by value when mapping credentials to avoid modifying the in-memory or persisted configuration.
