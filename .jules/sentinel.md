## 2025-02-18 - Prevent Credential Leakage in Config Serialization
**Vulnerability:** The CLI `tdb config show` command leaked sensitive tenant API keys when displaying the configuration to the user. While `AdminSecret` was explicitly masked via `display.AdminSecret = env.Config.MaskedAdminSecret()`, nested tenant `APIKey` entries were deeply referenced and leaked in the serialized YAML output.
**Learning:** Shallow copying a configuration struct (like `display := *env.Config`) containing nested maps of secrets (like `Tenants -> Keys -> APIKeyEntry`) doesn't create copies of the nested items. Serializing the shallow copy will iterate over the original maps, leaking their unmasked secrets (or modifying the original state if they are masked in-place).
**Prevention:** Implement a deep `MaskedClone()` method for the configuration that properly reallocates nested maps and applies masking logic to all secret fields (including tenant API keys) before serialization. Ensure this method is used in display commands like `tdb config show` instead of a shallow copy.
