## 2024-05-24 - Avoid double-encoding overhead with jsonRaw
**Learning:** In Go, when passing pre-encoded JSON (like `[]byte`) as a payload to an HTTP request where the client uses `json.NewEncoder`, it can lead to dangerous double-encoding overhead. A type assertion to skip encoding entirely (`bytes.NewReader`) when a payload implements specific methods (like `Bytes() []byte` and `isJSONRaw()`) provides a performant and safe way to pass pre-encoded JSON directly.
**Action:** Always check if JSON payloads are already pre-encoded (e.g. using a custom type like `jsonRaw`). When building internal HTTP clients, implement type checks to detect pre-encoded JSON types and use `bytes.NewReader` to skip `json.NewEncoder` overhead, while ensuring a marker method is used to prevent dangerous duck-typing.
