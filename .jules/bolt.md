## 2025-02-18 - Optimized String Building in CLI Output Table
**Learning:** `strings.Join` combined with creating a slice to hold `strings.Repeat` results creates excessive allocations and is much slower than writing directly to a pre-sized `strings.Builder`. Table border rendering string operations inside CLI loops were highly impacted by this pattern, leading to slower table formatting. Pre-calculating lengths and avoiding the slice allocation resulted in an approximately ~2.4x speedup in border string generation.
**Action:** Always prefer `strings.Builder` with `Grow` pre-calculated when assembling strings from components or repeating characters, especially in code executed repeatedly like table rendering. Avoid the `slice creation` -> `strings.Join` pattern when performance is a concern.
