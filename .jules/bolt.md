## 2024-05-18 - Avoiding overhead in JSON request construction and compact printing
**Learning:** `json.NewEncoder` does full validation and reflection even on primitive types wrapped in custom types like `JSONRaw []byte` that implement `MarshalJSON`. This creates severe overhead for pre-marshaled payloads. On the flipside, formatting huge slices using `json.Marshal` and then converting to string using `string(data)` leads to significant memory overhead.
**Action:** When a payload is already serialized (like `JSONRaw`), cast it and use `bytes.NewReader(raw)` directly rather than sending it through `json.NewEncoder(buf).Encode(payload)`. And when writing large compact JSON to `stdout`, stream it using `json.NewEncoder(out).Encode(value)` instead of `json.Marshal` followed by string conversion.
