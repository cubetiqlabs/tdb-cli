## 2023-10-25 - Optimize JSON Encoding for Pre-encoded Payloads
**Learning:** In the TinyDB CLI codebase, `json.NewEncoder` introduces unnecessary reflection and double-encoding overhead when processing pre-encoded JSON byte slices (`jsonRaw`). The memory also showed this context: "The codebase uses a custom jsonRaw type (underlying []byte) for pre-encoded JSON payloads. To optimize performance, type-assert for this type and pass it directly using bytes.NewReader rather than applying json.NewEncoder which causes reflection and double-encoding overhead."
**Action:** When a payload is known to be pre-encoded JSON data (like `jsonRaw`), use a type assertion to check its type and pass it directly to `bytes.NewReader(raw)` instead of encoding it again with `json.NewEncoder()`. This avoids the bottleneck and speeds up HTTP request construction.
